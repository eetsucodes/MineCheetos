# MineCheetos

A Java Fabric mod project targeting Minecraft 26.3 and Java 25. It is intended for single-player use. YOU WILL GET BANNED ON MULTIPLAYER!

Press **Right Shift** to open the menu, then choose **Toggle Flight**. Press **G** to toggle flight directly. Flight is available in survival/adventure in a local single-player world, not in multiplayer or while the world is open to LAN.

## Development

- Run the development client: `./gradlew runClient`
- Build the mod: `./gradlew build`

The built mod jar is written to `build/libs/`.
